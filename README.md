##DESCRIPTION
This repository includes all current projects I have completed at 42 which are all written in C
starting from the entrance examination which is 4 weeks of personal/ group projects.
List of projects of 42 core:
1. Libft: 42's first core project that teaches you the basics of C by coding a library from scratch
2. Printf: Recreating printf's function from scratch using va_list
3. get_next_line: Reading from a file descriptor and using static variables
4. pipex: Handling forks and pipes
5. fractol: Making fractals using mandelbrot and julia mathematical functions
6. push_swap: Using data structures and algorithm to sort numbers with the least space complexity (number of instructions)
7. Philosphers: solving the dining philosophers problem using mutexes
